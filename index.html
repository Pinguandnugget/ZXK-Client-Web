¿Cómo instalo ZXK Client?

Descarga el instalador oficial y sigue las instrucciones de instalación.

¿Qué hago si Windows muestra una advertencia?

No desactives el antivirus. Comprueba el archivo con el equipo de soporte y revisa el historial de protección antes de ejecutarlo.

¿Qué requisitos necesita?

Un equipo Windows compatible con Minecraft y el launcher.
