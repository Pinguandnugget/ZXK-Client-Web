¿Cómo instalo ZXK Client?
  1. Desde esta página, pulsa Descargar para Windows.
  2. Espera a que termine la descarga. Pulsa Ctrl + J en el navegador para localizar el instalador.
  3. Abre el archivo zxk-Client-Setup-*.exe desde Descargas. Sigue las instrucciones del asistente.
  4. Abre ZXK Client desde el acceso directo o menú Inicio e inicia sesión con tu cuenta de Microsoft que tenga Minecraft Java Edition.
  5. Selecciona PotitoSafio y pulsa Jugar. La primera ejecución puede tardar mientras se descargan los mods y archivos necesarios.

No cierres el launcher durante la instalación de archivos y mantén una conexión estable.

¿Qué hago si Windows bloquea el instalador?

Primero identifica qué tipo de aviso aparece. No todos significan lo mismo.

1. El navegador no descarga el archivo

  1. Abre el historial de descargas con Ctrl + J y revisa el motivo exacto.
  2. Comprueba que estás en esta página oficial y vuelve a intentar la descarga. Si es un fallo de conexión, prueba otro navegador o red.
  3. Si el navegador lo identifica como peligroso o malicioso, no fuerces la descarga.

2. Microsoft Defender SmartScreen

El aviso «Windows protegió su PC» puede aparecer cuando un instalador tiene poca reputación o no cuenta con una firma reconocida. No confirma por sí solo que exista malware.

  1. Haz clic en Más información para consultar el nombre de la aplicación y su editor, sin ejecutarla todavía.
  2. Comprueba que el archivo procede de la descarga oficial. Haz clic derecho en el archivo, elige Propiedades y revisa la pestaña Firmas digitales si existe.
  3. Analiza el archivo con Microsoft Defender. Si la firma no se puede verificar o persiste el bloqueo, no lo ejecutes hasta resolverlo.

3. El antivirus detecta una amenaza

  1. Abre Inicio → Seguridad de Windows → Protección contra virus y amenazas → Historial de protección.
  2. Revisa el nombre de la amenaza y el archivo afectado. Si utilizas otro antivirus, consulta su historial o cuarentena.
  3. No restaures archivos detectados ni desactives la protección. Conserva una captura del aviso.

Si después de estas comprobaciones el bloqueo continúa, contacta al equipo de soporte para que revise el instalador y el aviso.

¿Qué requisitos necesita mi computadora?

Estas son referencias orientativas para jugar a PotitoSafio con mods, no requisitos certificados mediante pruebas de hardware.

Mínimo orientativo

  • Windows 10/11 de 64 bits con actualizaciones de seguridad disponibles.
  • Procesador de 4 hilos.
  • 8 GB de RAM total; asignar aproximadamente 4 GB al juego.
  • GPU compatible con OpenGL 3.2 y controladores actualizados.
  • 10 GB de espacio libre como referencia inicial.
  • Shaders desactivados.

Recomendado

  • Windows 11 de 64 bits.
  • Procesador moderno de 4 núcleos o superior.
  • 16 GB de RAM total; asignar entre 6 y 8 GB según memoria disponible.
  • GPU dedicada con 4 GB de VRAM o superior para shaders ligeros.
  • 20 GB de espacio libre, preferiblemente en SSD.
  • Conexión estable a Internet.

Minecraft 1.21.1 necesita Java 21; utiliza el entorno gestionado por el launcher si está disponible. Se requiere una cuenta de Microsoft con licencia de Minecraft Java Edition. El espacio y la memoria necesarios pueden crecer con las actualizaciones.

Para consultar tu equipo, pulsa Win + R, escribe dxdiag y revisa las pestañas Sistema y Pantalla.

El juego se cierra, va lento o no conecta
  1. Reinicia el launcher y comprueba la conexión.
  2. Cierra aplicaciones innecesarias y desactiva los shaders desde las opciones de Minecraft.
  3. Utiliza la memoria recomendada por el launcher; no asignes toda la RAM disponible.
  4. Actualiza los controladores gráficos desde el fabricante y revisa el espacio libre en disco.
  5. Si el juego se cierra, copia el registro de errores desde la consola del launcher. Si no conecta, comprueba si el servidor está en mantenimiento.
Contactar al equipo de soporte

Si ninguna solución anterior funciona, abre un ticket en el canal de soporte del Discord oficial de PotitoSafio.

Incluye la versión del launcher, una captura del error, los pasos que ya probaste, tu versión de Windows y, si hay un cierre del juego, el registro de errores. No compartas contraseñas, códigos de inicio de sesión ni tokens.
