Centro de asistencia

¿Necesitas ayuda?

Hemos preparado esta guía para acompañarte desde la primera instalación hasta tu entrada al servidor.

Instala ZXK Client y entra a PotitoSafio
  1. Descarga: pulsa el botón Descargar para Windows de esta página. Encontrarás el instalador en tu carpeta Descargas.
  2. Instalación: abre el archivo ZXK Client Setup y completa el asistente. Después, inicia ZXK Client desde el menú Inicio o su acceso directo.
  3. Tu cuenta: inicia sesión con Microsoft desde el launcher. Utiliza la cuenta que tiene Minecraft Java Edition. Introduce tus credenciales únicamente en la página oficial de Microsoft.
  4. Preparación: selecciona PotitoSafio. Al pulsar Jugar, el launcher comprueba los archivos y descarga o actualiza el contenido necesario. No necesitas buscar los mods por separado.
  5. ¡A jugar! deja que termine la preparación y se abra Minecraft. La primera vez puede demorar más debido a la descarga de archivos.

En los siguientes inicios, el launcher vuelve a comprobar el contenido para mantener tu instalación al día.

¿Por qué aparece una advertencia de seguridad?

ZXK Client se distribuye como un instalador de Windows (.exe). Los sistemas de protección pueden mostrar advertencias al descargar aplicaciones nuevas o que todavía no cuentan con suficiente reputación. Una advertencia de reputación no equivale a una detección de virus.

Si Chrome o Edge no completa la descarga

  1. Descarga el instalador desde esta página oficial, no desde enlaces reenviados o copias de terceros.
  2. Pulsa Ctrl + J para revisar la descarga. Si indica un error de red, vuelve a intentarlo con una conexión estable.
  3. Si el aviso indica que el archivo es peligroso, conserva el mensaje exacto para poder identificar la causa.

Si aparece «Windows protegió su PC»

Este mensaje corresponde a Microsoft Defender SmartScreen. Pulsa Más información para consultar el nombre del archivo y del editor. Comprueba que coincide con el instalador descargado desde nuestra página y examínalo con tu antivirus (clic derecho sobre el archivo → analizar con Microsoft Defender; en Windows 11 puede estar en Mostrar más opciones). Si el bloqueo persiste o no puedes verificar el archivo, detén la instalación.

Si el antivirus detecta una amenaza

  1. Abre Seguridad de Windows → Protección contra virus y amenazas → Historial de protección.
  2. Busca el archivo de ZXK Client y anota el nombre de la detección. Si tienes otro antivirus, consulta su historial de alertas.
  3. No desactives el antivirus ni restaures un archivo marcado como amenaza. Una detección concreta requiere revisión, incluso si el archivo proviene de nuestra página.

Si no consigues resolverlo con estas comprobaciones, abre un ticket en nuestro Discord. Revisaremos el aviso y te indicaremos cómo continuar.

¿Qué requisitos necesita mi computadora?

Para disfrutar de PotitoSafio con sus mods, recomendamos las siguientes configuraciones. La memoria que necesitas depende de los mods activos, los shaders y los programas que tengas abiertos.

Configuración de entrada

  • Windows 10/11 de 64 bits con actualizaciones de seguridad disponibles.
  • Procesador de 4 hilos.
  • 8 GB de RAM total; asignar aproximadamente 4 GB al juego.
  • GPU compatible con OpenGL 3.2 y controladores actualizados.
  • 10 GB de espacio libre como referencia inicial.
  • Shaders desactivados.

Experiencia recomendada

  • Windows 11 de 64 bits.
  • Procesador moderno de 4 núcleos o superior.
  • 16 GB de RAM total; asignar entre 6 y 8 GB según memoria disponible.
  • GPU dedicada con 4 GB de VRAM o superior para shaders ligeros.
  • 20 GB de espacio libre, preferiblemente en SSD.
  • Conexión estable a Internet.

PotitoSafio utiliza Minecraft 1.21.1, que requiere Java 21. La configuración de memoria recomendada aparece en ZXK Client; no hace falta asignar toda la RAM manualmente. Se requiere una cuenta de Microsoft con licencia de Minecraft Java Edition. El espacio y la memoria necesarios pueden crecer con las actualizaciones.

Para consultar tu equipo, pulsa Win + R, escribe dxdiag y revisa las pestañas Sistema y Pantalla.

Soluciona errores de inicio, rendimiento y conexión

La descarga de mods no termina

Comprueba tu conexión y el espacio libre en disco. Cierra y vuelve a abrir ZXK Client si la descarga se ha detenido. El launcher comprobará el contenido al volver a iniciar.

Minecraft va lento

Utiliza la recomendación de RAM del launcher, cierra aplicaciones que no necesitas, desactiva los shaders y reduce la distancia de renderizado. Actualiza los controladores de tu tarjeta gráfica desde el fabricante.

Minecraft se cierra al iniciar

Abre la consola de ZXK Client y copia el registro del error. Comprueba que tienes espacio disponible y que la memoria asignada no supera la memoria libre de tu equipo.

No puedo entrar al servidor

Revisa los anuncios de mantenimiento de PotitoSafio y comprueba tu conexión a Internet. Reinicia el launcher para verificar que tienes los archivos actualizados.

Contactar al equipo de soporte

Estamos para ayudarte. Si después de seguir esta guía el problema continúa, abre un ticket en el canal de soporte del Discord oficial de PotitoSafio. Nuestro equipo revisará tu caso.

Incluye la versión del launcher, una captura del error, los pasos que ya probaste, tu versión de Windows y, si hay un cierre del juego, el registro de errores. No compartas contraseñas, códigos de inicio de sesión ni tokens.
